========================================
HOW IT WORKS
========================================

BEFORE:
-------
Student Table → Student can borrow books but cannot login
User Table → Separate, must be manually created

AFTER:
------
Student Table → Click "Link Account" → User created automatically
Both tables linked by EMAIL matching
Student can now LOGIN and use online system!

LINKING PROCESS:
----------------
1. Librarian opens Students page
2. Sees "Link Account" button for unlinked students
3. Clicks button → Modal opens
4. Reviews student details
5. Clicks "Create Account & Link"
6. System creates user with:
   - Role: Student (role_id = 3)
   - Username: From email (john@mail.com → john)
   - Password: student123
   - Email: Same as student profile
   - Full name: Same as student profile

KEY CODE SNIPPET:
-----------------
```php
case 'link_account':
    // Create a user account linked to student
    $db = getDB();
    
    // Check if email already exists
    $stmt = $db->prepare("SELECT id FROM users WHERE email = ?");
    $stmt->execute([$_POST['email']]);
    if ($stmt->fetch()) {
        setFlash('warning', 'User account already exists');
    } else {
        // Create new user account with student role
        $stmt = $db->prepare("
            INSERT INTO users (role_id, username, email, password, full_name) 
            VALUES (3, ?, ?, ?, ?)
        ");
        $username = explode('@', $_POST['email'])[0];
        $password = 'student123';
        
        $stmt->execute([
            $username,
            $_POST['email'],
            $password,
            $_POST['full_name']
        ]);
        
        setFlash('success', "Account created! Username: {$username}, Password: student123");
    }
    break;
```

TECHNICAL DETAILS
========================================

LINKING LOGIC:
--------------
Users and students are linked by EMAIL:
  SELECT u.* FROM users u 
  WHERE u.email = student.email 
  AND u.role_id = 3

USERNAME GENERATION:
--------------------
Email: john.doe@university.edu
