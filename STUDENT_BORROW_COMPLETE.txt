========================================
COMPLETE BORROW WORKFLOW
========================================

STEP 1: Student Browses Books
   Location: Student Dashboard → Browse Books
   Shows: All books with search/filter options

STEP 2: Student Selects Book
   Options: 
   - Click "Borrow Now" directly on card
   - Click "View Details" → "Borrow This Book" in modal

STEP 3: System Validates
   Checks:
   ✅ Student profile linked?
   ✅ Book available?
   ✅ Not already borrowed?
   ✅ Under borrowing limit?

STEP 4: Confirmation Dialog
   Message: "Do you want to borrow this book? Due date will be 14 days from today."
   Options: OK / Cancel

STEP 5: Create Borrowing Record
   Database: INSERT into borrowings table
   - student_id: From student profile
   - book_id: Selected book
   - borrow_date: Today
   - due_date: Today + 14 days
   - status: 'borrowed'
   - created_by: Current user ID

STEP 6: Update Book Stock
   Database: UPDATE books table
   - available_copies = available_copies - 1

STEP 7: Show Success
   Flash Message: "Book borrowed successfully! Due date: [date]"
   Redirect: Back to Browse Books page

STEP 8: View Borrowing
   Location: My Borrowings page
   Shows: 
   - Book details
   - Borrow date
   - Due date
   - Days remaining
   - Overdue warning (if applicable)

========================================
DATABASE OPERATIONS
========================================

ON BORROW:
----------
INSERT INTO borrowings (
    student_id, 
    book_id, 
    borrow_date, 
    due_date, 
    status,
    created_by
) VALUES (?, ?, ?, ?, 'borrowed', ?)

UPDATE books 
SET available_copies = available_copies - 1 
WHERE id = ?

VALIDATION QUERIES:
-------------------
-- Check availability
SELECT available_copies FROM books WHERE id = ?

-- Check duplicate
SELECT id FROM borrowings 
WHERE student_id = ? AND book_id = ? AND status = 'borrowed'

-- Check limit
SELECT COUNT(*) as total FROM borrowings 
WHERE student_id = ? AND status = 'borrowed'
